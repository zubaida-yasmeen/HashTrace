How it works

  • Reads file bytes in the browser.
  • Computes a SHA-256 digest with the Web Crypto API.
  • Compares the digest with the saved reference.
  • Exports a JSON manifest containing filename, size, timestamp, algorithm, and digest.

Important: the manifest itself must be protected. If an attacker can replace both the file and its reference manifest, this local demo cannot prove authenticity. For stronger provenance, sign manifests or store them in a trusted external system.
